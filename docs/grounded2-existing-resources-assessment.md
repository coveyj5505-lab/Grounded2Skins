# Existing Grounded 2 resources: crook and wings

## Result

A public SDK was found and downloaded. Stop expanding broad character probes. Use the SDK to validate exact reflected members, then test only movement/equipment/camera getters and relevant animation references in the user's build. V4 remains a pending targeted-component experiment; there is no need to repeat V3.

## Generic Unreal APIs, not Grounded 2 implementation proof

`USceneComponent::K2_AttachToComponent`, `SetVisibility`, `SetHiddenInGame` and `UPrimitiveComponent::SetCollisionEnabled` appear in the SDK's Engine module. They establish an engine-level attachment/visibility route. They do not establish the correct gameplay mesh/socket, replicated ownership, equipment-dependent policy or working Lua argument marshaling in this specific UE4SS build. Attach/show/hide must be controlled on an owned cosmetic component, not shared assets or stock equipment slots.

Switching a stance is not proof of switching an attack safely. Attack data/montages are connected to stamina, hit timing, range and damage. Merely calling the game's attack montage RPC, setting an animation field, or equipping a spear is not verified to preserve unarmed behavior. Keep visual spear-animation research separate from gameplay attack execution. Relaxed one-hand carry and two-hand attack blending remain an animation task, even with perfect state detection.

## UE4SS documentation and the shortest fallback

The requested [development docs](https://docs.ue4ss.com/dev/) were network-blocked, so the corresponding official documentation sources were fetched from [UE4SS main/docs](https://github.com/UE4SS-RE/RE-UE4SS/tree/main/docs) and compared with [v3.0.1/docs](https://github.com/UE4SS-RE/RE-UE4SS/tree/v3.0.1/docs). User log identifies Beta git `ca6f9b4c`; release-tag docs are a version baseline, not proof every Beta function matches.

- [v3 Live Viewer](https://github.com/UE4SS-RE/RE-UE4SS/blob/v3.0.1/docs/feature-overview/live-view.md): `GuiConsoleEnabled=1` and `GuiConsoleVisible=1` expose the UI. It supports searching, viewing and watching loaded-object properties. Select the LOCAL pawn's movement/equipment instances; avoid CDO/default objects or remote players. Watch specific states without editing. Main/dev documents richer filters, function search and watch-file export; verify those controls exist before relying on them in this Beta.
- [v3 dumpers](https://github.com/UE4SS-RE/RE-UE4SS/blob/v3.0.1/docs/feature-overview/dumpers.md): C++ header generation default Ctrl+H, object dump Ctrl+J, bindings defined by `Mods/Keybinds/Scripts/main.lua` (check actual installed file). Those are optional one-time standing-state operations, not airborne controls. Generated headers describe reflected types/signatures and do not automatically reproduce working native layouts, function bodies or cooked compatibility. Leave `LoadAllAssetsBeforeGeneratingCXXHeaders` and `LoadAllAssetsBeforeDumpingObjects` off; forced loads are unnecessary for already loaded target components.
- [New SDK generator](https://github.com/UE4SS-RE/RE-UE4SS/blob/main/docs/feature-overview/sdk-generator.md) exists in main/dev; the corresponding `v3.0.1` files return404. Do not instruct the user to upgrade/reinstall a working UE4SS just for that newer button.
- [Reflection](https://github.com/UE4SS-RE/RE-UE4SS/blob/v3.0.1/docs/lua-api/classes/uobjectreflection.md) gives `GetProperty(name)` metadata. Resolve exact known fields/functions and validate types before reading/calling. Metadata is not permission to convert delegates/containers, and Lua pcall cannot catch native access violations.
- [RegisterHook](https://github.com/UE4SS-RE/RE-UE4SS/blob/v3.0.1/docs/lua-api/global-functions/registerhook.md) targets loaded UFunctions, not arbitrary multicast delegate property names. `OnGliderMovementModeChanged` is a delegate in movement, not automatically a directly hookable UFunction. A receiver UFunction or read-only getter polling may be simpler, once actual signatures are verified. Do not bind a hook just because an event-looking name exists.
